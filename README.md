# Tech-Layoff-Analysis-POWER-BI
Power-BI dashboard analysing technology layoffs and trends
## Project Overview

This project analyses technology layoffs using Power BI. The dashboard provides insights into layoffs by company, industry, geography, funding, and time.

## Tools Used

- Power BI
- Excel
- Data Cleaning
- Data Analysis
- Data Visualization
